# Backend

Contains FastAPI application, database models, ML models, and detectors.

- deploy_server.py – Main API server
- database.py – Database models
- 	rain_model.py – Trains success classifier
- 	rain_performance_model.py – Trains performance predictor
- 	rend_model.pkl – Success classifier model
- performance_model.pkl – Performance predictor model
- detectors/ – Movement and trend detectors
- legacy/ – Older API versions
